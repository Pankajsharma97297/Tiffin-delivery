# MIDDO Admin Panel

Separate browser admin panel for managing the MIDDO app ecosystem.

## Structure

- `src/main.jsx` - React/Vite entry point
- `src/App.jsx` - current admin shell, to be split feature-by-feature
- `src/styles.css` - current responsive admin styling
- `PROJECT_STRUCTURE.md` - target long-term project architecture
- `index.html` - web entry file
- `package.json` - Vite React scripts

## Screens Included

- Dashboard
- Orders and tracking
- Subscriptions and skipped meals
- HomeChefs
- Customers and profiles
- Plans
- Wallet
- Reviews
- Support
- Notifications

## Run

```bash
cd admin-panel
npm install
npm run dev
```

Then open `http://localhost:5174`.
